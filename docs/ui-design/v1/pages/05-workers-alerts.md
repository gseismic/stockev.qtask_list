# 页面设计：Worker 监控 `/workers` + 告警中心 `/alerts`

## Worker 监控 `/workers`

- 服务场景：S4 · 频率：中
- P1 = Worker 心跳与 stale 状态；P2 = 恢复操作；P3 = Redis 内存详情

### 布局

```
┌────────────────────────────────────────────────────────────┐
│ KPI: 在线 4 · 失联 1 ⚠ · processing 总数 12 · Redis 62%     │
├────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────┐ │
│ │ worker_id      队列            heartbeat   状态         │ │
│ │ fetch-3        quote:5min      2s 前       ● 在线       │ │
│ │ kline-1        day-kline:fetch 8min 前     ⚠ 失联 [恢复]│ │ ← P2
│ └────────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────────┤
│ Redis 内存 (P3): used 1.2G / peak 1.4G / 阈值 2G  ▓▓▓▓░ 62%│
└────────────────────────────────────────────────────────────┘
```

- `<WorkerTable>`：数据源 `list_workers`。失联行提供 `[恢复]`（对应 `recover`，恢复该 worker 绑定的 processing 任务），活跃 worker 不提供恢复按钮（与 API 拒绝语义一致），显示"运行中"。
- `<RedisMemoryCard>`：数据源 `/api/health`，超阈值整卡红色。

### 状态

- 空：无在线 Worker 引导（给出 `qtask worker --module …` 命令示例）。
- 失联 Worker 恢复需确认：提示"将把该 Worker processing 中的 N 个任务移回主队列"。

## 告警中心 `/alerts`

- 服务场景：S1、S3 · 频率：高
- P1 = 未处理告警列表；P2 = 定位跳转与标记处理；P3 = 历史已处理

### 布局

```
┌────────────────────────────────────────────────────────────┐
│ Tabs: 未处理 (3) · 已处理          规则说明 ⓘ               │
├────────────────────────────────────────────────────────────┤
│ 🔴 dlq:1   stockev:quote:5min 的死信队列出现 1 条任务        │
│            10:02 ·  [定位到 DLQ]  [标记已处理]               │
│ 🔴 worker   kline-1 心跳超时（最后心跳 08:12）              │
│            08:15 ·  [查看 Worker]  [标记已处理]              │
│ 🟡 failed%  day-kline:fetch 最近 50 条失败率 8% (>5%)        │
│            07:40 ·  [查看失败任务]  [标记已处理]              │
└────────────────────────────────────────────────────────────┘
```

- `<AlertList>` → `<AlertItem>`：严重度色点 + 规则名 + 队列/对象 + 触发时间 + 操作。同队列同类告警合并为一条计数（`dlq:3 条`）。
- 规则说明 ⓘ 展开折叠面板，列出 states.md §3 的规则与阈值（透明化，避免"为什么告警"困惑）。
- 已处理 tab 保留记录（localStorage），显示处理时间。

### 状态

- 空态："🎉 当前没有告警" + 一句规则摘要。
- 错误：与全局错误条一致。
- 极端：告警 >99 条时按队列折叠为分组标题，组内展开。
